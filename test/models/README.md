# Meshes used by tests and benchmarks

Copies kept in this repository so that nothing outside it is read (only the HyperFEM package itself is
needed for the HyperFEM tests and benchmarks).

| File | Used by | Origin |
|---|---|---|
| `test_static_EM.msh` | EM 3D monolithic (`test/hyperfem`, `benchmark/phase0/em3d.jl`) | HyperFEM.jl `test/models/test_static_EM.msh` (commit aa4fe23) |
| `Short_magnet.msh` | hMRE 2D (`test/hyperfem`, `benchmark/phase0/hmre2d.jl`, `benchmark/phase1/solve.jl`) | Adv_Mater_Ultra_Soft_Magnet `data/models/Short_magnet.msh` (commit 71a610e) |
| `test_stokes.msh` | Stokes simulation (`test/hyperfem/simulations`) | HyperFEM.jl `test/models/test_stokes.msh` (same SHA-256) |
| `test_BC2.msh` | MeshMovement simulation (`test/hyperfem/simulations`) | HyperFEM.jl `test/models/test_BC2.msh` (same SHA-256) |
| `turek2d.msh` | Turek DFG 2D-1 Navier-Stokes simulation (`test/hyperfem/simulations`) | `benchmark/meshes/generate.jl turek 0.02` (7 402 triangles) |

Refined meshes with the same geometry are generated by `benchmark/meshes/generate.jl` (git-ignored).
